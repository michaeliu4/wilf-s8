# Manuscript revision 8 and computational companion

This release pairs the manuscript *The Ray–West parameter and the Wilf
classification of permutations of length eight* with its source, code,
certificates and retained computational evidence.

The mathematical contributions include the 4,755-class S8 classification
with sharp cutoff 14, a deletion-graph cycle basis, the interval statistic
for j derived from Ray–West, the layered g3 correction, and exact monotone
cluster formulas. The revision clarifies the projection-preserving
contraction, credits the existing track parametrization and polynomial
antecedents, and proves a cubic comparison between monotone and separated
families. It also adds two vector figures and input-validation tests for
the cluster counter. The core S8 certificate is unchanged.

Revision 8 clarifies the conjectural status of Ray and West's degree
bound, the abstract and the Hegarty attribution, and adds the primary
Hegarty reference. The standard quick check now validates the recorded
move provenance, and the component counter rejects malformed input.

See README.md for the entry commands, docs/REPRODUCING.md for scope and
cost, and docs/REVISION8_VERIFICATION.md for the current checks. The
earlier docs/VERIFICATION.md remains the revision-7 record. This
release does not claim an all-length compact statistic for g3, an
unrestricted higher-codimension component theorem, formal verification,
or journal acceptance.
